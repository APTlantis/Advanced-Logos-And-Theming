Syntax highlighting

Twelve language examples with bundled offline Prism grammars and downloadable source.

Illustrative code; host integration and native editor behavior require separate review.

  • JavaScript

    Classes, private fields, array transforms, template interpolation and regular expressions.

  • TypeScript

    Typed records, generics, interfaces, union types and optional values.

  • Python

    Dataclasses, type annotations, comprehensions, exceptions and formatted strings.

  • C#

    Records, LINQ, nullable values, interpolation and pattern matching.

  • C++

    Headers, structs, templates, lambdas, containers and stream output.

  • HTML

    Semantic markup, attributes, embedded CSS and embedded JavaScript displayed as source.

  • CSS

    Custom properties, selectors, pseudo classes, functions and responsive rules.

  • JSON

    Nested objects, arrays, strings, booleans, null and numeric values.

  • SQL

    A common-table expression, aggregation, joins, CASE expressions and ordering.

  • Bash

    Functions, arrays, quoting, parameter expansion, conditionals and pipelines.

  • PowerShell

    Parameters, typed values, hashtables, pipelines and error handling.

  • TOML

    Tables, arrays of tables, inline tables, dates and multiline strings.
